# WaveSink 1.2.1

- Right-click the engine status pill to reset the audio engine. Confirmation
  restarts PipeWire, then relaunches WaveSink.
- Settings supports a custom PipeWire reset command; the default detects
  Omarchy or installed PipeWire user services.
- Relaunch failures appear in the error banner.
- Updated Vite to resolve the dependency audit failure.

Existing profiles remain intact. Resetting the engine briefly interrupts audio.
