# WaveSink 1.1.2

A fix-only release on top of 1.1.1. Nothing to do when upgrading.

## Fixed in 1.1.2

- **The AppImage no longer disappears on a system without PipeWire.** It now
  starts and shows a dialog saying PipeWire was not found and asking you to
  install it, instead of exiting with nothing on screen.

  PipeWire is a hard requirement that WaveSink takes from the system rather
  than bundling, so on a machine without it the dynamic loader stopped the app
  before any of its own code ran — which meant the existing "couldn't connect
  to PipeWire" dialog never got the chance to appear. Launched from a menu or
  by double-clicking, nothing happened at all. The AppImage now checks for the
  library first and explains the problem.

  Only the AppImage was affected: the `.deb`, `.rpm` and Arch packages all
  depend on PipeWire, so the package manager will not let you install into
  that state.

### Packages

`.deb`, `.rpm`, Arch (`.pkg.tar.zst`), AppImage and a Nix flake, with
`SHA256SUMS`.
