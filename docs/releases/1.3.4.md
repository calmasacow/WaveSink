# WaveSink 1.3.4

Updating from the title bar now restarts WaveSink into the new version.

## Changed

- **WaveSink restarts itself after an update.** Once the terminal has
  installed the new package, it restarts WaveSink: through its systemd user
  service when autostart is enabled, otherwise by stopping the old process and
  starting the new one. The terminal stays open to show the result. If the
  download, the checksum or the install fails, or the install prompt is
  declined, WaveSink keeps running untouched.
- An AppImage update restarts WaveSink once the new image is in place.

## Fixed

- **HDMI outputs follow the display, not the port.** A mix sent to an HDMI
  device (such as an Elgato 4K X capture card) could end up playing into a
  different monitor after cables moved, because the GPU's HDMI audio outputs
  are numbered by slot. WaveSink now remembers which display each HDMI output
  was bound to. At startup and on profile load, it finds the slot that display
  is on now, points the mix there and switches the card's audio profile to
  match.

## Upgrade notes

The restart lives in the copy doing the updating, so updating from 1.3.3 or
earlier still needs one manual restart. Updates from 1.3.4 onward restart on
their own.

Existing profiles, mixes, settings and the selected theme remain intact.
Restarting briefly interrupts WaveSink's audio routing.

## Packages

Linux x86_64: `.deb`, `.rpm`, Arch (`.pkg.tar.zst`), AppImage and a Nix flake,
with `SHA256SUMS`. Use the [installation instructions](../../README.md#install)
or download assets from this release.
