# WaveSink 1.3.0

Update notifications in the title bar, the engine reset introduced for 1.2.1,
and current dependencies across the whole stack.

## Added

- **Update checks in the title bar.** A pill beside the engine status checks
  GitHub for a newer stable release at launch and every six hours, and turns
  accent-coloured when one is waiting. Clicking an up-to-date pill checks
  again; clicking an available one opens the update dialog. Colours follow the
  current theme, including Omarchy palettes.
- **Updating from the dialog, suited to how WaveSink was installed.** An
  AppImage updates itself: the new image is downloaded, verified against the
  release `SHA256SUMS`, and swapped in, with the running version left working
  until it is restarted. A packaged install (Arch, Debian/Ubuntu, Fedora or
  openSUSE) needs root, which a background application should not take for
  itself, so the dialog opens a terminal that shows the package command and
  asks for the password there. Where no terminal is found the command stays on
  screen to copy. A Nix install is pointed at its own flake or profile, since
  its version is declared, not installed.
- **Skipping a version.** The dialog offers to skip the release on offer. The
  pill then sits muted rather than calling attention to itself, and the next
  release raises it again. A skipped release is still named on the pill and the
  dialog still opens, so it stays one click from being installed.
- **Reset the audio engine from the engine status pill.** Right-click it, and a
  confirmation restarts PipeWire and relaunches WaveSink. Settings accepts a
  custom reset command; the default detects Omarchy or the installed PipeWire
  user services. Relaunch failures appear in the error banner. (Prepared for
  1.2.1, which was never published.)

## Changed

- Dependencies updated across the npm, Cargo and GitHub Actions stacks,
  including Tauri 2.12.2, React 19.3.1 and `global-hotkey` 0.9, and the Vite
  update that clears the dependency audit failure.

## Upgrade notes

Existing profiles, mixes and settings remain intact. Resetting the audio engine
briefly interrupts audio.

Update checks contact the GitHub releases API every six hours and on launch.
WaveSink never acquires root: the AppImage path replaces only its own file, and
every packaged install is updated by a terminal that asks for the password
itself.

The AppImage self-update path is covered by unit tests but has not yet been
exercised end to end on a real AppImage install. Packaged installs were
verified on Arch.

## Packages

Linux x86_64: `.deb`, `.rpm`, Arch (`.pkg.tar.zst`), AppImage and a Nix flake,
with `SHA256SUMS`. Use the [installation instructions](../../README.md#install)
or download assets from this release.
