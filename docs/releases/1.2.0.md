# WaveSink 1.2.0

Elgato hardware controls and an integrated Omarchy audio panel, with fixes for
Dock capture startup and meters when input Audio FX is enabled.

## Added

- **Elgato hardware controls in the input panel.** Wave XLR, XLR Dock, Wave:3
  and XLR Dock MK.2 expose their supported gain, hardware mute, headphones and
  monitoring controls. XLR models include confirmed 48 V switching. Native
  packages include USB permissions; OpenWave is not required. See
  [supported devices and setup](../elgato-hardware.md).
- **Omarchy audio panel.** Installed per user on first launch, the panel follows
  each user's profiles, mixes and inputs. Choose a bar volume mix per profile,
  adjust levels and mute, switch profiles or open the full mixer. Meter scale
  matches WaveSink; colors follow the current Omarchy theme. The compact footer
  keeps the mixer button and profile selector side by side.
- **Visible panel status and recovery.** Settings shows Active/Inactive, with
  Enable or Reapply actions and progress/success feedback. Restoring the OS
  panel requires two confirmations and explains how to enable WaveSink again
  without reinstalling. See [panel setup and restoration](../omarchy-panel.md).

## Fixed

- Legacy XLR Dock capture stays active while WaveSink uses the device. WaveSink
  waits for capture before linking its headphone mixes, including when the
  window is hidden. This mitigates the reproduced playback-before-capture
  silence; it cannot recover a Dock already streaming zeros or control other
  applications' startup order.
- Mix meters exposed through the control socket follow the actual mix output
  with Audio FX enabled, keeping Stream Deck/OpenDeck meters aligned with
  WaveSink. Internal FX streams ignore stale desktop-restored volume and mute.

## Upgrade notes

Existing profiles remain intact. On Omarchy, first launch replaces the audio
widget with WaveSink's panel and backs up the prior configuration. Settings
can restore it; opting out persists across restarts and upgrades.

AppImage and source users need the Elgato USB permission rule installed
separately. Follow the [USB setup instructions](../elgato-hardware.md#usb-permissions).
Only the original XLR Dock was physically checked; other listed models have
protocol fixture coverage. Phantom switching was not physically exercised.

## Packages

Linux x86_64: `.deb`, `.rpm`, Arch (`.pkg.tar.zst`), AppImage and a Nix flake,
with `SHA256SUMS`. Use the [installation instructions](../../README.md#install)
or download assets from this release.
