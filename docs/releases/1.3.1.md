# WaveSink 1.3.1

Fifteen more Omarchy palettes in the theme picker.

## Added

- **Fifteen community Omarchy themes.** Aetheria, Archwave, Ash, Ayaka, Azure
  Glow, Black Gold, Matrix, Moodpeak, Neon Dusk, Retro Bloom, RetroPC, Space
  Monkey, Synthwave '84, Terminus and Waveform Dark join the twenty-two stock
  palettes, bringing the picker to thirty-seven. Each was read from the theme's
  own files, so WaveSink matches what the rest of the desktop is showing.
  Choosing "Follow Omarchy" still tracks the active desktop theme and needs no
  picking at all.

## Upgrade notes

Existing profiles, mixes and settings remain intact, and the selected theme is
kept.

Each palette keeps the colour roles its author chose. A few themes assign those
roles unconventionally - Matrix, for instance, is green from end to end and
uses a near-white for red - so WaveSink's danger and online cues follow suit
and may not read as red and green in every theme. Primary and secondary text
was checked for contrast against each background.

## Packages

Linux x86_64: `.deb`, `.rpm`, Arch (`.pkg.tar.zst`), AppImage and a Nix flake,
with `SHA256SUMS`. Use the [installation instructions](../../README.md#install)
or download assets from this release.
