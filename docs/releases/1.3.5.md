# WaveSink 1.3.5

Mixes sent to HDMI follow the display instead of the GPU's audio slot.

## Fixed

- **HDMI outputs follow the display, not the port.** A mix sent to an HDMI
  device (such as an Elgato 4K X capture card) could end up playing into a
  different monitor after cables moved, because the GPU's HDMI audio outputs
  are numbered by slot. WaveSink now remembers which display each HDMI output
  was bound to. At startup and on profile load, it finds the slot that display
  is on now, points the mix there and switches the card's audio profile to
  match.

## Upgrade notes

Existing HDMI outputs record their display the first time 1.3.5 starts, using
whatever display is on that slot at that moment. If a mix is already playing
into the wrong screen, pick the right output again once after updating.
Re-cabling while WaveSink runs is picked up on the next restart or profile
load.

Existing profiles, mixes, settings and the selected theme remain intact.
