# WaveSink 1.1.0

Stream Deck control. WaveSink can now be driven from a Stream Deck through
OpenDeck, and the deck always shows what the mixer is actually doing.

## New

- **Control socket.** WaveSink listens on a private local socket
  (`$XDG_RUNTIME_DIR/wavesink/control.sock`) that only your user account can
  open. Stream controllers and scripts use it to:
  - set or step input levels, per-mix sends and mix levels
  - toggle mutes, routes and solo
  - load a profile, or step to the next or previous one
- **Live updates.** Connected controllers are told about every change, wherever
  it came from: the window, the tray, hotkeys or a profile trigger. Live meter
  levels are available too, even while WaveSink is in the tray.
- **The window keeps up.** A change made from a Stream Deck shows up in the
  mixer straight away.
- **WaveSink for OpenDeck**, the first plugin built on it (coming to the
  OpenDeck plugin store):
  - Input, Mix, Route, Solo and Profile actions
  - live meters on Stream Deck+ dials
  - keys in your inputs' own icons and colours

Changes from the socket go through the same checks as the window: levels still
top out at 100%, and routing rules still apply. The protocol is documented in
[docs/control-socket.md](https://github.com/calmasacow/WaveSink/blob/main/docs/control-socket.md).

## Upgrading

Nothing to do. Your routing, levels and profiles are untouched.

### Packages
