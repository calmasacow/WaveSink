# WaveSink 1.3.3

A fix for updating packaged installs from the update dialog.

## Fixed

- **Update now works on Arch, Debian/Ubuntu, Fedora and openSUSE.** The
  terminal the dialog opens installed straight from the download URL. pacman
  then looked for a signature file the release does not ship and stopped with a
  404, and dpkg cannot install from a URL at all. The terminal now downloads the
  package, checks it against the release `SHA256SUMS`, and installs the local
  file, as the install scripts do. A damaged or tampered download is rejected
  before the package manager runs.

## Upgrade notes

The fix lives in the copy doing the updating, so a 1.3.0, 1.3.1 or 1.3.2
install still carries the old command. Update this once with the
[installation instructions](../../README.md#install); the dialog handles every
update after that.

Existing profiles, mixes, settings and the selected theme remain intact.

## Packages

Linux x86_64: `.deb`, `.rpm`, Arch (`.pkg.tar.zst`), AppImage and a Nix flake,
with `SHA256SUMS`. Use the [installation instructions](../../README.md#install)
or download assets from this release.
