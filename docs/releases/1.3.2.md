# WaveSink 1.3.2

A layout fix for the update dialog.

## Fixed

- **The update dialog's buttons no longer overflow the panel.** The dialog
  carries three actions and a download URL, more than the width the app's
  two-button dialogs use, so the row ran past the left edge and labels broke
  inside words. The dialog is now wider, its buttons sit on one row, and
  release notes moved to a link beneath the command rather than competing with
  Update and Copy.
- Dialog button rows wrap as a whole rather than overflowing, and a button
  label no longer breaks mid-word, so a narrow window stacks buttons cleanly.
  This applies to every dialog.

## Upgrade notes

Existing profiles, mixes, settings and the selected theme remain intact.

## Packages

Linux x86_64: `.deb`, `.rpm`, Arch (`.pkg.tar.zst`), AppImage and a Nix flake,
with `SHA256SUMS`. Use the [installation instructions](../../README.md#install)
or download assets from this release.
